# 🎓 CampusConnect

**Discover campus events. Explore clubs. Never miss an opportunity.**

CampusConnect is a campus event discovery and deadline management platform designed initially for students at **NIT Warangal (NITW)**. It aims to make it easier for students—especially first-years—to discover events, workshops, competitions, and club activities that are often announced across different platforms.

## ✨ Features

- 🗓️ **Event Discovery** — Explore campus events and activities.
- ⏰ **Deadline Tracking** — Keep track of event registration deadlines.
- 🔎 **Search and Filter** — Find opportunities by keyword or category.
- 💙 **Save Events** — Save interesting opportunities for later.
- 🏛️ **Club Discovery** — Explore student clubs and activities.
- 🌙 **Light and Dark Mode** — Switch between appearance themes.
- 👥 **Role-Based Interface** — Student and society representative views.
- 📱 **Responsive Design** — Designed for laptop and mobile screens.
- ➕ **Event Submission** — Representatives can add events in the prototype.

## 🛠️ Built With

## 🚀 Getting Started

### Run locally

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Explore the CampusConnect prototype.

No build tools are required to run the current frontend prototype.

## 🌐 Deployment

CampusConnect can be hosted as a static website using **GitHub Pages**.

1. Open your repository's **Settings**.
2. Select **Pages**.
3. Under *Build and deployment*, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder.
5. Click **Save**.

## ⚠️ Current Limitations

This is an early-stage frontend prototype.

- Event information may include illustrative sample data and should not be treated as official announcements.
- Saved events, preferences, and submitted events use browser storage.
- Submitted events are not automatically shared between different users or devices.
- A shared backend and database would be needed for centralized event management.

## 🎯 Vision

CampusConnect aims to bring campus opportunities into one accessible place so students can discover activities, stay aware of deadlines, and participate more actively in campus life.
